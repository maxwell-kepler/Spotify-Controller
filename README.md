# Spotify-Controller

# REFACTORING THE ENTIRE CODE BASE TO MAKE IT MORE USABLE.

# Virtual Environment
1. Create with: python -m venv venv
2. Activate with venv\Scripts\activate

# Spotify
1. Connect the API by initializing
2. Check if there's a device connected
3. If so, allow access to features

## Features
1. Check if the device is playing
2. Get
    - Song Features
    - Song Analysis
    - Current Track
    - Current Volume
    - Current Playback
3. Play
    - Next track
    - Previous track
    - Specific 
        - track
        - album
        - Artist
4. Change
    - Volume
        - Up
        - Down
5. Alternate playback
